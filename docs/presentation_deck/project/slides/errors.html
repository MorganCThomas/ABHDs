Q8 · RESULT

Four analysis choices change the results

Incomplete EC numbers

are not classes; counting them inflates function transfer

Sequence distance

a clipped global score ties 94% of pairs; local alignment avoids this

Matched controls

one fixed cutoff removes 202 structure pairs but 5 sequence pairs; match by quantile

Cavity volumes

depend on model and anchor; report only consistent contrasts

Source: robustness analyses (Questions 4 and 7)

Related sensitivities: the ABHD label definition (EPHX3/4 and LIPJ/K/M/N), pocket-shell statistics that treat residues as independent, and orthologue sets that contain paralogs.
