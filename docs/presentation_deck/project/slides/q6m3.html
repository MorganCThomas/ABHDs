Q6 · METHOD

Test whether the pocket shell differs

1 Superpose

TM-align; a residue is diverged if displaced more than 3 Å or unaligned

2 Shell

Residues within 6 Å of the reference active-site cavity

3 Test

Fisher test, plus a circular-shift test that keeps residue runs; active–active pairs as baseline

Source: scripts/19_inactive_vs_active.py (A3, A5)

Residues in a segment are not independent, so the plain Fisher test overstates significance; the circular-shift test slides the divergence mask along the chain 2,000 times. Both reference directions are reported.
