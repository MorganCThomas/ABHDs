ABHD = “α/β-hydrolase domain-containing”, a name given by discovery order

110 genes come from merging two databases (Question 1); ABHD12B is a 21st ABHD-named gene outside the merged set. The ABHD names were assigned as genes were found, so the name may reflect history, not biology. Our test: do structure, sequence and function agree with the name?
