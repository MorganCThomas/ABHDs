Q2 · METHOD

A backbone-angle rule for the nucleophile elbow

1 Rule

φ 30–90°, ψ −170 to −80°; strand before, helix after; confidence ≥ 70

2 Residue

Ser, Cys, Thr or Asp at the turn is the nucleophile call

3 Benchmark

31 UniProt nucleophiles, a sequence-motif baseline, 36 threshold settings, experimental structures

Source: scripts/10_catalytic_sites.py; src/abhd/catalytic.py

The thresholds were set from known nucleophiles (ABHD2, ABHD14B, LPL, MGLL), which is why the benchmark result is training recall. The rule uses the nucleophile Cα angles on the AlphaFold model; the residue type is applied afterwards.
